## Stage Classification Priority
Evaluate in the following fixed priority order. The first matching rule wins.

### 1. DEFENSIVE / 防禦期
Match if either:
- structural_failure = true
OR
- Price < MA60 AND M7 < 35

If structural_failure = true and previous_stage is non-adjacent:
- stage_override = true
- stage_override_reason is required

### 2. MARKUP / 主升期
All must be true:
- Price > MA20
- Price > MA60
- Price > MA120
- MA20 > MA60
- MA20 slope > 0
- M7 >= 75
- MHE >= 60
- Relative Strength = strong

### 3. PRE_MARKUP / 主升準備期
All must be true:
- Price > MA20
- Price > MA60
- MA20 slope > 0
- M7 >= 65
- MHE >= 60
- MARKUP rule is not matched

### 4. STRENGTHENING / 轉強期
All must be true:
- Price > MA20
- M7 >= 65
- short/swing MHE evidence is improving
- PRE_MARKUP and MARKUP are not matched

### 5. HIGH_ROTATION / 高檔輪動期
Long-term bullish structure remains valid:
- Price > MA60
- MA60 trend is non-negative
AND either:
- prior M7 >= 75 and current M7 < 75
OR
- Rotation deteriorates by at least one level
AND DEFENSIVE is not matched.

### 6. HIGH_CONSOLIDATION / 高檔整理期
All must be true:
- long-term structure remains bullish
- Price is near MA20 or MA60
- MHE >= 45
- 35 <= M7 < 65
- HIGH_ROTATION is not matched

### 7. BASE_BUILDING / 築底期
All must be true:
- Price <= MA60 OR Price <= MA120
- recent low is no longer deteriorating
- M7 is rising OR MHE is rising
- DEFENSIVE is not matched

### 8. CONSOLIDATION / 整理期
Fallback stage when none of the higher-priority rules match and either:
- 35 <= M7 < 65
OR
- evidence state is mixed

## Stage Normalized Score for Ranking
- MARKUP = 90
- PRE_MARKUP = 80
- STRENGTHENING = 70
- HIGH_ROTATION = 65
- HIGH_CONSOLIDATION = 60
- BASE_BUILDING = 50
- CONSOLIDATION = 40
- DEFENSIVE = 20

## Determinism
Given the same:
- spec version
- data contract version
- engine version
- input snapshot

the classifier must produce the same stage and normalized score.
