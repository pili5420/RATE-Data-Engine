# RATE-SPEC-20260919-004

System: RATE V11  
Type: Specification Change / Stage Operational Definition Completion  
Status: APPROVED / FROZEN  
Extends: RATE-SPEC-20260914-003

This specification freezes operational definitions for Stage evidence. It does not change Stage priority, normalized scores, M7/MHE/Rotation formulas or ranking rules.

## Stage evidence definitions

- `price_near_ma20_ma60`: `abs(Close - MA20) / MA20 <= 0.03 OR abs(Close - MA60) / MA60 <= 0.03`, using unrounded values.
- `CURRENT_LOW20`: minimum Low over sessions `t-19..t`; `PRIOR_LOW20`: minimum Low over `t-24..t-5`; `recent_low_no_longer_deteriorating = CURRENT_LOW20 >= PRIOR_LOW20`. Require 25 valid sessions; never substitute Close for Low.
- `structural_failure`: `Close < MA120 AND MA20 < MA60 AND MA60 < MA120`.
- `evidence_state_mixed`: `(M7 >= 50 AND MHE < 45) OR (M7 < 45 AND MHE >= 60)`.
- `relative_strength_strong`: `RS >= 65`.
- `ma60_trend_non_negative`: `MA60(t) >= MA60(t-5)`.
- `long_term_bullish`: `Close > MA60 AND MA60 >= MA120`.
- `m7_rising`: `M7(t) > M7(t-5)`; `prior_m7 = M7(t-5)`.
- `mhe_rising` and `short_swing_mhe_improving`: both `MHE(t) > MHE(t-5)`.
- Rotation classes use the existing RATE-PLS-V1.1 boundaries: ACCELERATING >=80, STRENGTHENING >=65, FLAT >=45, WEAKENING >=30, WARNING <30. `rotation_deteriorated` is true only when the current class is at least one level weaker than the class at `t-5`.

## Historical calculation and bootstrap

All t and t-5 M7, MHE and Rotation values must be replayed with the frozen formulas and each date's eligible cross-section. Inputs after the as-of date are excluded. Require at least seven aligned sessions to reconstruct the prior session's own five-session lookback. Require 25 valid Low observations for the recent-low rule.

For the first Production 07:30 only, when there is no valid 30-symbol persisted Stage state, the previous completed session's Stage may be reconstructed from authorized historical evidence. Label its source `RECONSTRUCTED_FROM_AUTHORIZED_HISTORICAL_EVIDENCE`; prior transition/override metadata is `NOT_RECONSTRUCTED`. The control/genesis chain ID is metadata only and cannot stand in for market evidence. After the first valid 07:30 state, use persisted per-symbol Stage/M7/MHE/Rotation state; do not repeat reconstruction.

Every field records value, source session/date, source type, definition and spec version. Missing evidence fails closed. The fixture `artifacts/RATE_0730_DECISION_STATE.json` is never Production prior state.

No Production snapshot or state persistence is authorized by this specification change itself.
